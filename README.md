To-Do List Pro 📝

📌 Project Description

To-Do List Pro is a simple task management application developed using Python. It helps users organize daily activities by adding, viewing, searching, deleting, and completing tasks.

✨ Features

- Add Tasks: Create tasks with a title, priority, and due date.
- View Tasks: Display all tasks with their details and status.
- Filter Tasks: View all, pending, or completed tasks.
- Delete Tasks: Remove tasks that are no longer needed.
- Search Tasks: Find tasks using keywords.
- Complete Tasks: Mark pending tasks as completed.
- Input Validation: Validate task names, priorities, dates, and menu choices.

🛠️ Technologies Used

- Python 3
- "datetime" module for date validation
- Lists and dictionaries for task management
- Loops and conditional statements
- Exception handling

🚀 How to Run

1. Install Python 3 or open an online Python compiler such as Programiz.
2. Create a file named "main.py".
3. Copy the project code into the file.
4. Click Run to start the application.
5. Select an option from the menu to manage your tasks.

📋 Menu Options

Option| Function
1| Add Task
2| View / Filter Tasks
3| Delete Task
4| Search Tasks
5| Complete a Task
6| Exit

⚠️ Limitations

- Tasks are stored temporarily in memory.
- Tasks are lost when the program stops or restarts.
- The application runs in a command-line interface.
